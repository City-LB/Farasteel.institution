1.1 What is HTML?

HTML stands for HyperText Markup Language. It is the standard language used to create web pages — HTML tells the web browser what should appear on the screen.

Think of HTML as the skeleton of a human body. Without the skeleton, the body cannot stand — without HTML, there is no webpage.

HTML does not create colors, animations, or advanced functionality. Its main responsibility is to organize and structure webpage content.

Example: Every website you have ever visited — Google, Facebook, YouTube, Amazon, Netflix — was first built with HTML.

Definition: HTML is the standard markup language used to structure and display content on web pages.

1.2 Meaning of HyperText

HyperText simply means text that links to another document. When you click "Home," "About," or "Contact" on a website, those clickable pieces of text are called hyperlinks — each one can open another webpage.

1.3 Meaning of Markup Language

Markup means adding special tags that tell the browser how information should appear. Instead of writing plain "Welcome," HTML uses:

<h1>Welcome</h1>

The browser understands that <h1> means "display this as a large heading."

1.4 Why Was HTML Created?

Before HTML, sharing documents over the Internet was difficult, and scientists needed a way to connect research documents together. In 1989, Sir Tim Berners-Lee invented HTML so researchers around the world could share documents using hyperlinks. Today, billions of people use HTML every day without even realizing it.

1.5 History of HTML

  • HTML 1.0 (1991) — very basic: only headings, paragraphs, and links
  • HTML 2.0 (1995) — introduced forms and better structure
  • HTML 3.2 (1997) — added tables, scripts, and improved formatting
  • HTML 4.01 (1999) — introduced CSS support, better accessibility, and more attributes
  • XHTML (2000) — a stricter version of HTML where every tag had to be properly closed
  • HTML5 (2014) — the latest major version, introducing audio, video, canvas, SVG, semantic tags, local storage, better forms, and mobile support

HTML5 is the version developers use today.

1.6 Who Invented HTML?

Tim Berners-Lee invented HTML in 1989 while working at CERN in Switzerland. He is also known as the inventor of the World Wide Web (WWW).

1.7 What is a Web Browser?

A browser is software that reads HTML code and displays it as a webpage. Examples include Google Chrome, Microsoft Edge, Mozilla Firefox, Apple Safari, Opera, and Brave. Without a browser, HTML files cannot be viewed properly.

1.8 How Does a Website Work?

User → Browser → Internet → Web Server → HTML File → Browser Displays the Website

A user types a website address (for example, www.example.com). The browser sends a request to the server, the server returns an HTML file, and the browser reads that HTML and displays the webpage.

1.9 HTML vs CSS vs JavaScript

LanguagePurpose
HTMLCreates the structure of a webpage
CSSStyles the webpage — colors, fonts, spacing, layout
JavaScriptAdds interactivity and functionality

Simple analogy: imagine building a house — HTML is the bricks, walls, and roof (the structure); CSS is the paint, decorations, and furniture (the appearance); JavaScript is the electricity, doors, and alarms (the behavior). Together, these three technologies form the foundation of modern websites.

1.10 Features of HTML

  • Easy to learn and free to use
  • Platform-independent and lightweight
  • Supported by all modern browsers
  • Search-engine friendly
  • Works with CSS and JavaScript
  • Continuously updated

1.11 Advantages of HTML

  • Easy syntax and fast loading
  • Free and open standard
  • Cross-platform compatibility
  • Excellent browser support
  • Foundation of every website
  • Works well with other web technologies

1.12 Limitations of HTML

HTML alone cannot create animations, store data permanently, connect to databases, perform calculations, handle user authentication, or build complete web applications. These tasks require CSS, JavaScript, and backend technologies.

2.1 What is a Development Environment?

A development environment is the collection of tools you use to write, edit, test, and manage your code. Think of it as a carpenter's workshop — just as a carpenter needs a hammer, saw, and measuring tape, a web developer needs software tools to build websites.

A typical HTML development environment includes a computer, a code editor, a web browser, a file manager, and (optionally, for basic HTML) an internet connection.

2.3 Choosing a Web Browser

A web browser reads HTML code and displays it as a webpage. Popular browsers include Chrome, Edge, Firefox, Safari, Opera, and Brave. For development, Chrome and Edge are commonly used because they include powerful Developer Tools.

2.4 Choosing a Code Editor

A code editor helps you write HTML faster and with fewer errors. Popular editors include Visual Studio Code, Sublime Text, Notepad++, Brackets, Vim, and Nano. This course recommends Visual Studio Code (VS Code) — it's free, lightweight, and widely used by professional developers.

2.5 Installing Visual Studio Code

Windows: download the installer, run it, accept the license agreement, click Next until installation begins, then finish and open VS Code.

macOS: download the macOS version, open the file, drag Visual Studio Code into Applications, and launch it.

Linux: install using your package manager or download the appropriate package for your distribution.

2.6 Understanding the VS Code Interface

When VS Code opens, you'll see the Activity Bar (Explorer, Search, Source Control, Run and Debug, Extensions), the Editor Window, the Terminal, and the Status Bar. Each part has a specific purpose to help you write and manage code efficiently.

2.7 Installing Useful Extensions

Extensions add extra features to VS Code. Recommended ones include Live Server, Prettier, Auto Rename Tag, Auto Close Tag, HTML CSS Support, Path Intellisense, and Color Highlight — these improve productivity and reduce coding errors.

2.10 Creating Your First HTML File

Open VS Code, create a new file, and save it as index.html. The .html extension is required — without it, the browser will not recognize the file as an HTML document.

2.11 Why "index.html"?

When a web server receives a request for a folder, it typically looks for a file named index.html first. For example, requesting https://example.com/ automatically loads index.html — which is why the homepage of most websites is named that way.

2.12 Writing Your First HTML Page

Type the following code into index.html:

<!DOCTYPE html>
<html>
<head>
    <title>My First Webpage</title>
</head>
<body>

    <h1>Welcome to HTML</h1>

    <p>This is my first webpage.</p>

</body>
</html>

Save the file.

2.13 Running Your HTML File

  • Method 1: double-click the HTML file — it opens in your default browser
  • Method 2: right-click the file, choose "Open With," and select your preferred browser
  • Method 3 (recommended): use the Live Server extension in VS Code — right-click inside the editor and choose "Open with Live Server." Your browser opens automatically and refreshes whenever you save changes

2.14 Saving Your Work

Always save your work before testing. Use Ctrl + S on Windows or Command + S on macOS — saving frequently helps prevent data loss.

2.15 Naming Files Correctly

Use lowercase letters, hyphens instead of spaces, and meaningful names — for example about.html, contact.html, or student-profile.html. Avoid names like About Page.html or My First Website.html; spaces and inconsistent capitalization can cause problems when websites are hosted online.

2.16 Common Beginner Mistakes

  • Saving as index.html.txt instead of index.html
  • Forgetting to save the file before testing
  • Misspelling HTML tags or deleting angle brackets (< or >)
  • Placing files in the wrong folders
  • Using spaces in file names
  • Editing the wrong file by mistake

3.1 What is an HTML Document?

An HTML document is a text file with the .html extension that contains HTML code. When opened in a web browser, the browser reads the code and displays it as a webpage.

Every HTML document follows a standard structure. This structure helps browsers understand and render the content correctly. The browser reads the document from top to bottom.

3.2 Basic Document Hierarchy

<html>
  ├── <head>   → Metadata (not visible on the page)
  └── <body>   → Visible Content

3.4 The <!DOCTYPE html> Declaration

This must be the first line of every HTML5 document.

<!DOCTYPE html>

Purpose: It tells the browser: "This document uses HTML5."

3.7 The <title> Element

The <title> defines the text displayed:

  • On the browser tab
  • In bookmarks
  • In search engine results

Example:

<title>Farasteel Academy</title>

The browser tab will display: Farasteel Academy

3.10 Example of a Complete Webpage

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Student Portal</title>
</head>
<body>
  <h1>Welcome Students</h1>
  <p>This is our first HTML page.</p>
</body>
</html>

When opened in a browser, the heading and paragraph are displayed on the page, while the metadata in the <head> works behind the scenes.

3.14 HTML Comments

Comments allow developers to leave notes in the code. Comments are ignored by the browser and are not displayed on the webpage.

Syntax:

<!-- This is a comment -->

Example:

<!-- Header Section -->
<h1>Farasteel Academy</h1>
<!-- End Header -->

3.15 HTML Validation

Always validate your HTML to ensure it follows the official standards. Proper indentation throughout the document helps readability. Open the file in a browser and verify that it displays correctly.

5.1 Headings

HTML provides six levels of headings, from <h1> (most important) to <h6> (least important). Use only one <h1> per page when possible for better SEO and accessibility.

5.2 Paragraphs

The <p> element creates a paragraph of text. Browsers automatically add space before and after paragraphs.

When to Use <br>

  • Addresses
  • Poems
  • Song lyrics
  • Contact information

Avoid using <br> repeatedly to create space between sections. Use CSS for layout and spacing.

5.5 Horizontal Rules

The <hr> element inserts a horizontal line. It is useful for visually separating content sections.

5.10 Quotations

Short Quotations — Use <q>.

<p>
  The lecturer said,
  <q>Practice every day.</q>
</p>

Long Quotations — Use <blockquote>.

<blockquote>
  Education is the most powerful weapon
  which you can use to change the world.
</blockquote>

Text Formatting Tags

  • <strong> — important text (usually bold)
  • <em> — emphasized text (usually italic)
  • <mark> — highlighted text
  • <small> — smaller text
  • <sub> — subscript
  • <sup> — superscript
  • <del> — deleted text
  • <ins> — inserted text
  • <code> — code snippets

6.15 Adding Images

The image element is <img>. It is a void (self-closing) element.

Example (absolute path):

<img src="https://example.com/logo.png">

The image is loaded from another website.

Best Practice: Use relative paths for your own project files whenever possible.

Important Image Attributes

  • alt — alternative text (required for accessibility)
  • width / height — dimensions (prefer CSS when possible)

17.1 Using iframes

The <iframe> element allows you to embed another HTML page or external service inside your page.

<iframe
  src="https://www.google.com/maps/embed?..."
  width="600"
  height="450"
  style="border:0;"
  allowfullscreen
  loading="lazy"
  referrerpolicy="no-referrer-when-downgrade">
</iframe>

Best Practices

  • Always provide a title attribute for accessibility
  • Use loading="lazy" when appropriate
  • Check whether embedding is permitted by the source
  • Avoid embedding untrusted content
