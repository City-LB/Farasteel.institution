Introduction to CSS

What is CSS?

CSS stands for Cascading Style Sheets. It is a stylesheet language used to describe the appearance and formatting of documents written in HTML.

Think of HTML as the structure of a house. CSS is the paint, furniture, decorations, lighting, flooring, and overall beauty of that house.

Without CSS: websites look plain, everything appears black and white, there are no colors, no animations, no layouts, and no professional appearance.

Why CSS Was Created

Before CSS existed, every webpage looked almost identical. Developers had to style each HTML element manually. This became difficult as websites became larger. CSS solved this problem by allowing one stylesheet to control the appearance of many pages.

Benefits include:

  • Cleaner HTML
  • Easier maintenance
  • Faster development
  • Responsive design
  • Better user experience

Advantages of CSS

  1. Separation of Content and Design — HTML contains the content, CSS controls the design. 
    h1{
    color:blue;
    font-size:40px;
}
  2. Reusable Styles — One CSS file can style an entire website.
  3. Faster Loading — Since CSS files are cached by browsers, websites load faster.
  4. Responsive Websites — CSS allows websites to adjust automatically for desktop, laptop, tablet, and mobile.
  5. Professional Appearance — Modern websites depend heavily on CSS for shadows, animations, layouts, glassmorphism, dark mode, and gradients.

Real-World Applications of CSS

CSS is used in banking websites, hospital systems, school portals, government websites, social media, e-commerce stores, portfolio websites, blogs, news websites, and mobile web apps — including Google, Facebook, Amazon, Netflix, and YouTube.

CSS Versions

  • CSS1 (1996) — Basic styling features.
  • CSS2 (1998) — Added positioning and media types.
  • CSS3 — Introduced modules including Flexbox, Grid, Animations, Transitions, Variables, Media Queries, Gradients, and Shadows. CSS3 is the standard used today.

How Browsers Read CSS

When a browser loads a webpage, it reads the HTML, builds the page structure, reads the CSS, applies the styles, and displays the styled webpage.

Chapter 6

CSS Units and Measurements

Learning Objectives

  • Understand CSS measurement units.
  • Choose the appropriate unit for different situations.
  • Build responsive layouts using relative units.

What Are CSS Units?

CSS units define the size of elements such as text, margins, widths, heights, and spacing.

h1{
    font-size:40px;
}

Here, 40px is the measurement.

Types of CSS Units

CSS units are divided into two categories:

Absolute Units — these have fixed sizes: px (pixels), cm (centimeters), mm (millimeters), in (inches), pt (points), pc (picas).

.box{
    width:300px;
}

Relative Units — these change depending on the screen or parent element: %, em, rem, vw, vh, vmin, vmax. Relative units are preferred for responsive design.

Pixels (px)

Pixels are the most commonly used unit.

h1{
    font-size:32px;
}

Advantages: easy to understand, precise sizing. Disadvantages: less flexible for responsive designs.

Percent (%)

Percentage is based on the parent element.

.container{
    width:80%;
}

If the parent is 1000px wide: 80% = 800px.

em

Relative to the parent font size.

body{
    font-size:20px;
}

p{
    font-size:2em;
}
Result: 40px

rem

Relative to the root (html) font size.

html{
    font-size:16px;
}

h1{
    font-size:2rem;
}
Result: 32px

Viewport Width (vw)

1vw = 1% of the browser width.

.hero{
    width:100vw;
}

Viewport Height (vh)

1vh = 1% of the browser height. Useful for hero sections.

.hero{
    height:100vh;
}

Choosing the Right Unit

PropertyRecommended Unit
Font Sizerem
Width%, vw
Heightvh
Paddingrem
Marginrem
Iconsem

Practical Example

.container{
    width:90%;
    max-width:1200px;
    margin:auto;
}

h1{
    font-size:2.5rem;
}

.hero{
    height:100vh;
}
Common Mistakes

❌ Using fixed pixels everywhere. ✔ Use relative units for responsive websites.

What is Flexbox?

Flexbox (Flexible Box Layout) is a one-dimensional layout system used to arrange elements in rows or columns. It helps developers align items, distribute space evenly, build responsive layouts, and reduce complex CSS code.

Basic Flex Container

<div class="container">
    <div>One</div>
    <div>Two</div>
    <div>Three</div>
</div>
.container{
    display:flex;
}
Result: One Two Three

Main Axis and Cross Axis

------------------------------>
        Main Axis

|
|
|
v

Cross Axis

The main axis follows flex-direction. The cross axis is perpendicular to it.

flex-direction

/* Row (default) */
.container{
    display:flex;
    flex-direction:row;
}
A B C 
/* Column */
.container{
    display:flex;
    flex-direction:column;
}

justify-content

Controls alignment along the main axis: center, space-between, space-around, space-evenly.

justify-content:space-between;
A B C

align-items

Controls alignment on the cross axis.

align-items:center;

Other values: flex-start, flex-end, stretch, baseline.

flex-wrap & gap

.container{
    flex-wrap:wrap;
}

.container{
    gap:20px;
}

flex-grow, flex-shrink, flex-basis

.item{
    flex-grow:1;
}

.item{
    flex-shrink:0;
}

.item{
    flex-basis:250px;
}

/* Shorthand */
flex:1;

Equivalent to flex-grow, flex-shrink, and flex-basis together.

Building a Responsive Navigation

    align-items:center;
}

Building Cards

What is CSS Grid?

Grid is a two-dimensional layout system. Unlike Flexbox (one direction), Grid controls rows and columns simultaneously.

Grid Container

.container{
    display:grid;
}

grid-template-columns & grid-template-rows

.container{
    display:grid;
    grid-template-columns:1fr 1fr 1fr;
}
+-----+-----+-----+
| A   | B   | C   |
+-----+-----+-----+
grid-template-rows:100px 200px;

gap

gap:20px;

Fraction (fr)

grid-template-columns:
1fr 2fr;

Column 2 is twice as wide.

Repeat()

grid-template-columns:
repeat(4,1fr);

Grid Areas

grid-template-areas:
"header header"
"sidebar main"
"footer footer";

Grid Item

.item{
    grid-column:1/3;
}

Responsive Grid

grid-template-columns:
repeat(auto-fit,minmax(250px,1fr));

This automatically adjusts the number of columns based on available space.

What is CSS Transform?

The transform property allows you to change an element's position, size, rotation, and shape without affecting the normal page layout.

Translate

Move an element.

.box {
 transform: translate(100px, 50px);
}
/* Translate X */
transform: translateX(100px);

/* Translate Y */
transform: translateY(-30px);

Rotate

.box {
 transform: rotate(45deg);
}

Scale

Increase or decrease size.

.card:hover {
 transform: scale(1.1);
}
/* Scale X */
transform: scaleX(2);

/* Scale Y */
transform: scaleY(.5);

Skew

transform: skew(20deg);

/* Skew X */
transform: skewX(15deg);

/* Skew Y */
transform: skewY(20deg);

Multiple Transforms

transform:
 translateY(-10px)
 rotate(5deg)
 scale(1.05);

Transform Origin

transform-origin: center;

Other values: top, bottom, left, right.

3D Transform & Perspective

transform: rotateY(180deg);
perspective: 1000px;

Glassmorphism Effect

.card {
 backdrop-filter: blur(20px);
 background: rgba(255, 255, 255, .2);
 border-radius: 20px;
}

Neumorphism Example

box-shadow:
 10px 10px 20px #d1d1d1,
 -10px -10px 20px white;

Learning Objectives

What Are CSS Variables?

CSS variables store reusable values.

:root {
 --primary: #0066ff;
}

Using Variables

button {
 background: var(--primary);
}

Multiple Variables

:root {
 --primary: #005eff;
 --secondary: #f5f5f5;
 --radius: 12px;
 --shadow: 0 10px 30px rgba(0, 0, 0, .2);
}

Updating Variables

.card {
 border-radius: var(--radius);
}

Dark Theme Example

.dark {
 --background: #111;
 --text: white;
}

Fallback Values

color: var(--primary, blue);
Advantages
  • Cleaner code
  • Easier maintenance
  • Consistent colors
  • Theme switching
  • Faster updates

Writing Clean CSS

✓ Use meaningful class names.

.hero-title {}

Avoid:

.a1 {}

Organize Your Code

Recommended order:

  1. Reset
  2. Variables
  3. Base styles
  4. Layout
  5. Components
  6. Utilities
  7. Responsive styles

Use External Stylesheets

<link rel="stylesheet" href="style.css">

Mobile-First Development

Write mobile styles first, then add styles for larger screens using media queries.

Reuse Components

.btn {
 padding: 12px 24px;
 border-radius: 8px;
}

Avoid Inline CSS

✗

<p style="color: red;">

✓

.text-danger {
 color: red;
}

Optimize Images

Use WebP, SVG, and compressed JPEG/PNG.

Keep Selectors Simple

.card h2 {}

Avoid very long selector chains that are difficult to maintain.

Accessibility Tips
  • Maintain sufficient color contrast.
  • Use readable font sizes.
  • Provide visible keyboard focus styles.
  • Avoid relying only on color to convey meaning.
  • Respect prefers-reduced-motion for users who reduce animations.

Popular methodologies: BEM (Block Element Modifier), SMACSS, OOCSS, and ITCSS.
